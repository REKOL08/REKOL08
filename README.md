### 🚀 Featured Projects

</div>

#### 🤖 [Librín — Library Chatbot & Reservation System](https://github.com/REKOL08/chatbot)
> AI-powered chatbot for Areandina's 3 campus libraries (Pereira, Bogotá, Valledupar)

Built with **Node.js + n8n workflows + Google Sheets**, Librín handles book reservations, renewals, and availability checks across three campuses — with sede-aware routing and role-based access for students, teachers, and staff.

`Node.js` `n8n` `Google Sheets` `HTML` `JavaScript` `Automation`

---

#### 📊 [Estadincho — Interactive Data Dashboard Generator](https://github.com/REKOL08/estadincho-gen-v5)
> Turn any Excel/CSV file into a fully interactive visual dashboard in one click

No code required. Upload your data, get an interactive dashboard. Built for non-technical users who need to understand their data fast.

`Python` `Data Visualization` `Excel` `CSV` `Dashboard`
