```yaml
role: AI Developer & Technical Library Specialist
org: Fundación Universitaria del Área Andina (Areandina) — BIDIG Library Innovation Team
study: Systems Engineering, 7th semester — Universidad Tecnológica de Pereira
mission: Turn institutional data into tools people can actually use
signal: campus_network(Pereira, Bogotá, Valledupar) → automation + AI
```

I design and ship the tools that run in the background of a library's daily operations — bots that reserve books, dashboards that turn a messy CSV into a decision, and browser-native apps that do serious statistics without ever touching a server. I like software that works the moment you open it: no install, no setup, no waiting on IT.
